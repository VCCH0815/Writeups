## Exploit
looking at exploitDB for anything related to Tomcat version 9, I found this [# Apache Tomcat - AJP 'Ghostcat' File Read/Inclusion (Metasploit)](https://www.exploit-db.com/exploits/49039).

So I started msfconsole and searched for anything related to ghostcat.

A few items that link to this exploit is the Apache Jserv Protocol on port 8009.
`8009/tcp open  ajp13      Apache Jserv (Protocol v1.3)`

The older version of Apache Tomcat treats any Apache Jserv Protocol connections with a high level of trust so no authentication is needed.

This can be leveraged if the web app has an upload option and a JSP script can be uploaded.


Back to metasploit, after setting RHOSTS and RPORT. a username and password is returned.
