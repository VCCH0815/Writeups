From the Recent Activity tab, it is known that the flag is hosted at `Internal/admin.php`, when accessed, an error says that it can only be accessed by localhost.


At the bottom of the page is a button that when clicked exports a pdf report of the server information, `server-info.php` as found before.


My hypothesis is that I can capture a request to export `server-info.php`, change the destination to `internal/admin.php`, accessing the directory.




I start by capturing a request of the export to pdf button using burp suite.

![](attachments/Pasted%20image%2020260430222934.png)

There is a url parameter that points to `server-info.php`, I change it to `internal/admin.php` and send the request, successfully retreiving the flag.
