On `cutie.png` the following warning occured.
`Warning : [minor] Trailer data after PNG IEND chunk`

`exiftool cutie.png `

There might be something at the end of this image.

Using `hexeditor`

`hexeditor cutie.png`

I see the following PNG signature.

`89 50 4E 47  0D 0A 1A 0A`

Pressing the Search function, `[shift] + W`, I search for the IEND chunk `49 45 4E 44`.

According to google,
```
· Structure:

o Length: 4 bytes (00 00 00 00 hex).

o Type: 4 bytes ( IEND or 49 45 4E 44 hex).

o Data: O bytes.

o CRC: 4 bytes (AE 42 60 82 hex, calculated for "IEND").
```

Using `binwalk cutie.png` I see a zip file appended at the end.


to extract this, I run `binwalk -e cutie.png`, which gives me the folder, `_cutie.png.extracted` with a `8702.zip` file.

However upon using `unzip` and `7z`, I could not unzip the file, it turns out there is a password that is needed for it. 

To access it, I use zip2john. I  run the following

`zip2john 8702.zip > output.hash` to get the hash

Then

`john --wordlist=/usr/share/wordlists/rockyou.txt output.hash` to brute force the hash

`alien            (8702.zip/To_agentR.txt)     `


now going back to the zip folder, I use 
`7z x 8702.zip` with the password `alien`

## Privilege Escalation
Now with SSH access, I try to escalate my privilege. I start by getting linPEAS onto the target machine. 

On my own machine, I `cd` to `/usr/share/peass/linpeas`, and run the following

`scp linpeas.sh james@10.49.186.213:/dev/shm`

Then, on the target machine, I `cd` to `/dev/shm` and run `chmod +x linpeas.sh`

Finally, I run `./linpeas.sh | tee linlog.txt`

using `grep cve linlog.txt` I grep for possible cve vulnerabilities.

I could not get the flag so I searched online and the answer was `CVE-2019-14287`
