## Privilege Escalation
Now that I have SSH access, I start to try and get root access. I start by using the command `sudo -l` to list the commands that I can run as root.

![](attachments/Pasted%20image%2020260226223444.png)

Searching for this at [Gtfobins](#GTFObins), I find a command I can run to get a root shell.

````
sudo tar cf /dev/null /dev/null --checkpoint=1 --checkpoint-action=exec=/bin/sh
````

**On the GTFObins site, sudo is not included but I had to include it for the shell to spawn as root, I do not know why**
